Protections, verified on-chain

Each guarantee is exercised against the real program with hostile inputs that must be refused. We publish what is guaranteed, not how anyone might try to break it.

✓Every note spends once

A note leaves a one-time marker on-chain when spent; any second attempt is refused by the program.

2 scenarios verified
✓Only valid proofs move funds

Every public detail of a transaction is recomputed by the program and bound into the proof. Change anything and it no longer verifies.

2 scenarios verified
✓Funds go where you said

Recipients and relayer fees are fixed by your proof. Nobody in between can redirect them.

1 scenario verified
✓Trades and lending are ring-fenced

Each trade or lending position gets its own escrow and signer and must pay out at least the minimum you approved (the app checks the quote against the market price first), or your input comes back as a private note.

7 scenarios verified
✓Simple, fixed fees

Nullifex’s fee is 0.3% when you shield, trade or withdraw. Private sends between Nullifex users have no Nullifex fee. Fees are kept apart from user funds and can only go to Nullifex’s treasury.

3 scenarios verified
✓Limited, two-step governance

Admin powers are narrow, can’t move user funds, and change hands only when the new holder accepts.

7 scenarios verified
✓Risky tokens are refused

Tokens with features that could endanger a shared vault are rejected when a vault is opened.

1 scenario verified
✓Spam and capacity limits

Empty transactions are refused and each token’s vault has a cap.

2 scenarios verified
✓No blocking by third parties

Outsiders can’t stop your spends or withdrawals by tampering with addresses ahead of time.

2 scenarios verified

By design

Your keys stay with you

Generated and encrypted in your browser; proofs are built there too. Relayers and indexers never get your keys or learn which notes are yours. Like any server they see your IP address, and the relayer sees the transactions it submits for you, which are public on-chain anyway.

No custodial path

The admin can pause and set limits, but no instruction lets anyone move notes without the owner's proof.

Isolated integrations

Swaps and lending run only through allowlisted programs, each confined to its own escrow.

Open and replaceable

Anyone can run a relayer or an indexer. The app checks the indexer's data against the Merkle root the Nullifex program itself records on-chain, so it can't be shown a balance that isn't there.
